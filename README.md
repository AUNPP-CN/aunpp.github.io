## 关于

本仓库托管 [AUNPP](https://aunpp.cn) 组织官网（GitHub Pages，纯 HTML + CSS + 原生 JS，无构建依赖）。

AUNPP 是一个热爱 **Among Us** 与 **Minecraft** 的组织——写模组、搭服务器、折腾一切和这两款游戏有关的东西。

## 参与贡献

对本仓库（官网页面）的改进建议，欢迎直接提 Issue 或 PR：

1. Fork 本仓库
2. 创建特性分支（`git checkout -b feature/AmazingFeature`）
3. 提交更改（`git commit -m 'Add some AmazingFeature'`）
4. 推送分支（`git push origin feature/AmazingFeature`）
5. 发起 Pull Request
